# Used Cars Price Prediction

Проект по прогнозированию стоимости автомобиля на вторичном рынке.

## Задача

По характеристикам автомобиля построить модель, которая оценивает его рыночную стоимость.

## Этапы

- загрузка и проверка данных;
- очистка и предобработка;
- EDA;
- генерация признаков;
- проверка мультиколлинеарности;
- отбор признаков;
- обучение и сравнение моделей;
- оценка качества;
- анализ важности признаков.

## Метрика

Качество модели оценивается по **MAPE (Mean Absolute Percentage Error)**.

## Стек

`Python` · `pandas` · `scikit-learn` · `Jupyter` · `regression` · `feature engineering`
